# 尸体清理

Morrow 桌面侧边栏的“尸体清理”位于“敌人”之后。选择保存在本地配置中，实际游戏文件通过右上角“写入游戏”统一预览、备份、校验、封装及写入。页面上的模式切换和恢复不直接安装文件。

## 模式与组合

| 设置 | 行为 |
| --- | --- |
| 原版 | 恢复尸体消退和清尸半径的原版字段 |
| 快速清场 | 使用原工具的 473 条尸体配方及 59 条 300 米半径配方，通常约 6 秒开始消退；特殊巨型单位保留原配方的较长延迟 |
| 小型单位快速消失 | 使用小型补丁的消退模式 3、加速度 100、最小 / 最大延迟 0；大型单位实际动作仍由游戏决定 |
| 碎块 2 秒清理 | 独立设置 210 条 Gore 记录的三项寿命，可与两种尸体模式组合 |

“快速清场＋碎块清理”组合使用快速清场的尸体策略和小型补丁的碎块策略。模式切换先恢复该功能拥有的原版字段，再应用所选配方，避免即时消退与 6 秒延迟互相叠写。其他生命值、伤害、部位等编辑保持不变。

“恢复原版清理参数”只恢复本功能的字段；全局“恢复原版”仍沿用编辑器的整文件恢复语义，配置保留，再次写入会重新应用。

## 数据与边界

- 配方以不可变原版实体数据 SHA-256 `dc6d52a14900942b2f59f56bf8ab1552259832202dcb0745c3c84a009ff5f98b` 校验版本，并校验目标表尺寸及哈希桶的记录顺序。
- 通过数据块类型定位 Health、CorpseDecayer、Gore 表；不使用游戏安装目录的硬编码偏移。只有目标表布局匹配时，才修改对应记录内字段。
- 小型补丁也修改了 Health 表中没有实体键的一条记录。因此配方明确覆盖全部 507 条 Health 记录，并由完整表布局和版本校验保护。
- 不支持的游戏版本或改过目标表记录顺序的 Mod 会显示原因并禁用此功能。若旧配置处于启用状态，会阻止写入；可在页面“停用旧清理配置”后继续编辑其他内容。
- 没有独立清理配置时，读取现有文件并识别已安装的两种配方；无法识别的已有自定义字段可保留。仅启用碎块清理时不会顺带重置已有自定义尸体模式。
- 配置文件为编辑器配置目录中的 `corpse_cleanup.ini`，严格按数据解析。支持撤销 / 重做；保存失败不修改工作副本。
- 继续使用已有游戏运行检查和外部文件变化保护。测试不启动游戏、不写真实游戏目录；实际消退动作和特殊单位仍需进入游戏验证。

## 来源与许可

数值行为来自用户提供的“尸体快速清理(非管理器模组需要手动安装).zip”和“小型单位尸体快速消失补丁.zip”。前者提供 GPL v3 的 `Corpse Cleanup Offline` 工具及配方，说明中注明其数据封装机制参考 [SHODAN-HORAI/SHODAN-Stat-Editor](https://github.com/SHODAN-HORAI/SHODAN-Stat-Editor)。本项目保留 GPL v3 许可，未推定未署名作者身份。

这里重新实现了统一的字段写入与冲突处理，只包含数值配方；不附带上述 ZIP 的游戏文件、DLL、Python 或 PowerShell 安装器。原始两个安装器不再需要运行。Flutter 界面继续适用其原有 Morrow / 第三方许可声明。

## 开发验证

按 `desktop/morrow/README.md` 使用 Flutter analyze、Flutter test 和 Windows release build。新增测试包括侧边栏位置、独立碎块开关、全局预览 / 确认写入、版本不符禁用控件。

数据回归在 Windows 上执行：

```text
python tests/test_corpse_cleanup.py --vendor <包含 lupa 和 PyNaCl 的目录> --output <隔离输出目录>
```

也可将这两个依赖安装到开发环境后省略 `--vendor`。测试使用 LuaJIT 运行真实 `hostdata` / `gamedata`，加解密桥接到 PyNaCl；输入来自仓库自带原版明文，`game.dll` 只是隔离目录内包含目标哈希的测试占位文件。与原始两个模组的规范化明文 SHA-256 独立对照，覆盖组合、模式切换、恢复外部补丁、重启保留、封装回读、撤销重做、失败回滚和版本 / 表布局拒写。

2026-11-04 本地验证：9 项数据回归、15 项 Flutter 检查（含 1 项可选页面渲染导出）通过，Flutter analyze 无问题，Windows release 编译通过。使用 Flutter 3.47.9 / Dart 3.13.7，锁文件仅同步 SDK 约束所需的 meta / vector_math 版本。Rust 宿主和 Lua 运行库未修改，沿用并核对上游 v4.6.0 ZIP 的 SHA-256：`2af9c50ccce2307bc389ad00a9108bd5504b852b21938a71cdff7b8814397dd1`。未进行游戏内对局验证。
